  • Film, musiqi, süni intellekt, dizayn, oyun və sosial media xidmətləri bir platformada toplanır.
  • Hər məhsul üzrə qiymət, müddət və əsas istifadə məlumatları ayrıca göstərilir.
  • Sifariş prosesi qısa, sadə və mobil cihazlarda rahat istifadə ediləcək şəkildə qurulub.

Aktivləşdirmə və istifadə

Aktivləşdirmə nə qədər çəkir?

Ödəniş təsdiqləndikdən sonra məlumatlar qısa müddətdə təqdim olunur. Məhsuldan asılı olaraq dəqiq proses fərqlənə bilər.

Məhsul qaydalarında icazə verilmirsə e-poçt, şifrə və təhlükəsizlik məlumatlarını dəyişməyin.

Problem yaranarsa nə etməliyəm?

Əlaqə kanalları vasitəsilə sifariş məlumatı ilə müraciət edin. Dəstək komandası statusu yoxlayacaq.

Təhlükəsizlik və qaydalar

Məlumatlarımı necə qoruyum?

Hesab məlumatlarını üçüncü şəxslərlə paylaşmayın, icazəsiz dəyişiklik etməyin və məhsul səhifəsindəki qaydalara əməl edin.

Geri qaytarma şərtləri haradadır?

Geri qaytarma şərtləri ayrıca məlumat səhifəsində göstərilir və məhsul qaydalarına görə tətbiq edilir.

Hansı məhsulu seçəcəyimi bilmirəm?

Müqayisə və ən yaxşı seçim səhifələrindən istifadə edin, sonra məhsul səhifəsində qiymət və qaydaları yoxlayın.

Sifariş və aktivləşdirmə necə işləyir?

1. Məhsulu seçin

Kateqoriya, qiymət, müddət və istifadə məqsədinə görə məhsulu seçin.

2. Qaydaları oxuyun

Məhsul səhifəsində hesab tipi, müddət, istifadə qeydləri və təhlükəsizlik məsləhətləri göstərilir.

3. Sifarişi tamamlayın

Sifariş forması mobil və desktop üçün sadə saxlanılıb. Məlumatları diqqətlə daxil edin.

4. Aktivləşdirməni alın

Ödəniş təsdiqləndikdən sonra aktivləşdirmə məlumatı təqdim olunur.

5. Dəstəkdən istifadə edin

Sual və problem yaranarsa əlaqə kanalları vasitəsilə dəstək ala bilərsiniz.
